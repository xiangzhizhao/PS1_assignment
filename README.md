# PS1 Assignment

## Changes in the U.S. Wage Distribution, 2007–2024

This repository contains the replication code, tables, figures, and research note for a propensity-score reweighting analysis of changes in the U.S. real hourly wage distribution between 2007 and 2024 using CPS data.

### Files

- `ps_assignment_data_prep.R` — data preparation and empirical analysis
- `report-2.pdf` — research note
- `Figure1_log_real_wage_density.png` — log real wage density
- `Figure2_real_wage_cdf.png` — empirical CDF of real hourly wages
- `Figure3_counterfactual_wage_distribution.png` — actual and counterfactual wage distributions
- `Table1_descriptive_statistics.csv` — descriptive statistics
- `Table2_regression_results.tex` — regression results
- `Table_balance_diagnostics.csv` — covariate balance diagnostics
- `Table_mean_wage_decomposition.csv` — mean wage decomposition
- `Table_quantile_decomposition.csv` — quantile decomposition

### Data

The analysis uses CPS data. Raw CPS data are not included in this repository.
